# 一年薄肌计划 PWA（第一版）

## 包含功能
- 首页目标摘要与快速入口
- 体重记录、近30条趋势图、最近7次均值
- 饮食记录：餐次、食物份量、热量/蛋白质估算及备注
- 训练记录：训练类型、动作、重量/组数/次数、时长、主观强度、身体反馈
- 已知个人偏好档案
- JSON全量备份/恢复、CSV导出
- PWA manifest 与 service worker

## 当前预置数据说明
预置了2026-11-08至11-14体重记录；其中11-09、11-11等历史数据带有待核实备注。11-13训练记录需要用户点击“把这次训练加入日志”才会写入，避免重复或未经确认自动入账。饮食日志尚未批量预置，因为此前食堂份量、油量和食材生熟重有估算误差。

## iPhone安装
必须先部署到HTTPS静态网站。部署后用Safari访问网址，点“分享”→“添加到主屏幕”。本地HTML文件直接打开不等同于已安装PWA。

## 数据隐私与备份
数据默认保存在当前浏览器 localStorage，不会自动上传服务器。清理Safari网站数据、换浏览器或换设备可能丢失数据，请定期导出JSON备份。导入JSON会覆盖当前数据，导入前请先备份。

## 部署方式（任选其一）
将本文件夹中的 index.html、manifest.json、sw.js 上传到支持静态站点和HTTPS的托管服务。部署根目录应能直接访问 index.html。之后用iPhone Safari打开网站。
